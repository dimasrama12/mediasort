# PhotoSort Features

PhotoSort is an AI-powered desktop application designed to streamline the process of organizing large collections of photos and files.

## Core Features

### 1. AI-Powered Grouping
- **Visual Similarity**: Automatically groups similar-looking photos using perceptual hashing (pHash) algorithms.
- **Temporal Grouping**: Organizes files based on time clusters (same hour, day, or custom range).
- **Hybrid Analysis**: Combines both visual and temporal data for maximum accuracy.

### 2. High-Performance Preview
- **Futuristic 2026 UI**: High-contrast, sleek interface with smooth animations and theme support.
- **Dynamic Zoom & Rotate**: Full-size image preview with adjustable zoom levels and rotation controls.
- **Virtual Scrolling**: Handles thousands of files smoothly without performance degradation.

### 3. Precision Manual Sorting
- **Keyboard Shortcuts**: Assign folders to keys `1-9` for instant, one-touch sorting.
- **Drag & Drop**: Intuitive visual sorting by dragging files directly into target folders.
- **Multi-Select Workflow**: Organize batches of files simultaneously.

### 4. Safety & Management
- **Integrated Trash System**: Safely move files to a dedicated trash area with full restoration capabilities.
- **Contextual Operations**: Quick access to rename, copy path, and delete actions.
- **Real-Time Stats**: Instant feedback on folder file counts and total sizes.
